# Visual Assets Brief

Design specifications for Aura launch assets. For designers and content creators.

---

## Brand Colors

Based on design tokens, the brand should use:

**Primary:**
- Deep stone/gray tones (like the moai 🗿)
- High contrast blacks
- Pure whites

**Accents:**
- Fire red/orange for gains, wins, hot content
- Ice blue for stats, leaderboards
- Gold for #1 rankings

**Avoid:**
- Pastels (too soft for competitive vibe)
- Corporate blues
- Generic gradients

---

## Typography Style

**Headlines:**
- Bold, heavy weights
- Sans-serif
- All caps for emphasis on big numbers
- Think: sports broadcast graphics

**Body:**
- Clean, readable sans-serif  
- Medium weight
- Tight line height for impact

**Numbers (Aura counts, ranks):**
- Display prominently
- Tabular figures
- Large size relative to other text

## Animation Principles

### In-App Animations

**Like Animation:**
- Heart scale up (1.0 → 1.3 → 1.0)
- Duration: 300ms
- Easing: Ease-out
- Haptic feedback: Light impact

**Aura Gain Animation:**
- Number count up
- Small "+[amount]" appears and floats up
- Duration: 500ms
- Color: Gold or green

**Rank Change Animation:**
- Rank number slides/morphs
- Directional indicator (↑↓)
- If significant jump, celebration animation
- Duration: 700ms

**Battle Vote Animation:**
- Percentage bar fills
- Real-time vote count
- Winning side pulses
- Duration: Ongoing (live)

**Challenge Entry Submission:**
- Upload progress
- Success checkmark
- "Entered" confirmation
- Duration: Based on upload speed + 500ms confirmation

**Technical:**
- [ ] Correct dimensions for platform

- [ ] Correct format (PNG, JPG, MP4, etc.)
- [ ] High resolution (2x for mobile)
- [ ] Safe zones respected
- [ ] Text readable at small sizes

**Brand:**
- [ ] Uses approved colors
- [ ] Typography consistent
- [ ] Tone matches brand voice
- [ ] No corporate/generic language
- [ ] Moai or aura iconography present

**Content:**
- [ ] Clear message
- [ ] CTA present (when needed)
- [ ] No typos
- [ ] Numbers/stats accurate
- [ ] Username format correct (@username)

**Accessibility:**
- [ ] Sufficient color contrast
- [ ] Text not on busy backgrounds
- [ ] Alt text written (for social)
- [ ] Captions for videos

## Motion Graphics Guidelines

### Animation Duration Standards

**Micro-interactions:** 200-400ms
**Transitions:** 400-700ms  
**Celebrations:** 1000-1500ms
**Looping animations:** 3-5s loops

### Easing Functions

**Standard:** Ease-out cubic
**Bouncy (celebrations):** Spring (tension: 300, friction: 20)
**Smooth transitions:** Ease-in-out

### When to Animate

✅ **Do animate:**
- Likes
- Aura gains
- Rank changes
- Battle votes
- Challenge entries
- Notifications
- Loading states
- Success states

❌ **Don't animate:**
- Static text
- Profile images (unless interaction)
- Navigation (too distracting)
- Background elements

---

## Accessibility Considerations

### Color

- Don't rely on color alone to convey info
- Maintain 4.5:1 contrast ratio minimum
- Provide dark mode variants

### Typography

- Minimum 12px font size for body text
- Minimum 16px for buttons/CTAs
- Clear hierarchy (headings, subheads, body)

### Motion

- Provide reduced motion variants for animations
- Don't use flashing content (seizure risk)
- Keep autoplay videos muted by default

### Alt Text

Write descriptive alt text for all images:

**Bad:** "Aura screenshot"
**Good:** "Mobile app screenshot showing a leaderboard with the top 10 users ranked by aura points"

```

aura-explainer-video-tiktok-1080x1920-v1.mp4
aura-icon-app-store-1024x1024-v3.png
```

### Version Notes

Keep a changelog:
- v1: Initial concept

- v3: Final for launch
