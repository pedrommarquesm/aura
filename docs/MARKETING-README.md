### 🎬 3. Visual Assets Brief
**File:** `docs/visual-assets-brief.md`

Design specifications for your creative team:

**Brand Guidelines**
- Colors: Stone grays, high contrast blacks/whites, fire red accents
- Typography: Bold sans-serif, sports broadcast aesthetic
- Icon: Moai emoji (🗿) minimalist interpretation

**App Store Assets**
- Icon design concepts
- Screenshot specifications (6 screens with captions)
- Preview video structure (30s breakdown)

**Social Assets**
- Announcement graphics specs
- Leaderboard update templates
- Battle result graphics
- Challenge winner cards
- Stats graphics
- Tutorial carousels

**Video Content**
- 60s explainer video script and structure
- 15s feature showcase videos (battles, challenges, rank ups)
- UGC templates users can share

**Animation Guidelines**
- Like animation: 300ms, ease-out, haptic feedback
- Aura gain: Number count up, +amount floats
- Rank change: 700ms with celebration for big jumps

**Ad Specs**
- TikTok: 9:16, 9-15s, under 500MB
- Instagram Reels: 9:16, 15-30s
- Instagram Stories: 9:16, 3-5s per frame
- Feed ads: 1:1 square, 1080x1080px

## How to Use This

### Phase 1: Pre-Launch (Start Now)

**Week 1-2: Foundation**
1. Read through all three docs
2. Set up social accounts using brand guidelines
3. Brief design team with visual assets doc
4. Begin creating content stockpile

**Week 3-4: Content Creation**
1. Film TikTok/Reels scripts from launch content pack
2. Design social graphics per visual assets brief
3. Build landing page with provided copy
4. Create app store assets

### Phase 2: Launch Week

**Day 0: Launch**
1. Post announcement content (provided in launch content pack)
2. Activate paid ads (strategy in marketing plan)
3. Reach out to influencers (brief provided)
4. Monitor metrics dashboard

**Day 1-7: Momentum**
1. Follow daily content calendar
2. Respond using provided response templates
3. Share user content
4. Adjust ad spend based on performance

### Phase 3: Post-Launch

**Week 2-4: Sustain**
1. Weekly challenges and community spotlights
2. Scale what's working, cut what's not
3. Expand influencer program

**Week 5-8: Scale**
1. Increase ad budget to winning platforms
2. Launch referral program
3. Announce Season 1
