## Discord Servers - How to Find & Engage

### Finding Servers

**Method 1: Disboard.org**
1. Go to https://disboard.org
2. Search: "Gen Z", "memes", "TikTok", "teenage"
3. Sort by member count
4. Target: 1,000-100,000 members

**Method 2: Discord Search**
1. Use Discord's server discovery (in-app)
2. Browse "Meme" and "Social" categories
3. Check "Popular near you"

**Method 3: Ask Your Network**
1. Survey your target audience
2. Ask "What Discord servers are you in?"
3. Get direct invites

### Target Server Types

**Ideal:**
- Gen Z meme servers
- School/university community servers
- Gaming communities (Fortnite, Valorant, Minecraft)
- Social hangout servers
- Shitposting servers

**Good Server Indicators:**
- Active chat (messages every few minutes)
- 18-25 age demographic
- Casual/meme culture
- Not overly moderated
- Open to discussing apps/new things

**Red Flags:**
- Dead chat (messages once per day)
- No meme culture
- Very strict rules ("no self-promo" prominent)
- Different demographic

### Engagement Strategy

**Week 1: Lurk & Learn**
1. Join 10-15 servers
2. Read rules carefully
3. Observe conversation style
4. Note what people share
5. Don't mention app yet

**Week 2: Participate**
1. Join conversations naturally
2. Share memes (not your app)
3. React to messages
4. Build genuine presence
5. Make 20-30 messages per server

**Week 3: Soft Mention**
1. When relevant to conversation
2. Example: Someone posts aura moment → "this should be tracked fr"
3. If asked, share the app
4. Don't spam
5. Let others discover profile

**Week 4: Early Access Offer**
1. If you're established in server
2. Message mods about partnership
3. Offer early access codes for server
4. Create dedicated channel (if they allow)
5. Let community grow organically

### Partnership Approach

**DM to Server Owners:**
```
hey! noticed your server has great meme culture

I built an app that tracks aura points with real leaderboards

thought your community might fw it

would you be down to give early access to the server? could create a dedicated channel for it

no pressure if not, just thought it'd be a good fit 🗿
```

**What to Offer:**
- Early access codes for all members
- Dedicated role (e.g., "Beta Tester")
- Dedicated channel (#aura-app)
- First to see new features
- Server leaderboard feature (future)

**What to Ask:**
- Pin in announcements (one time)
- Dedicated channel
- Let culture develop naturally
- Genuine feedback

## Telegram Channels - How to Find & Engage

### Finding Channels

**Method 1: In-App Search**
1. Open Telegram
2. Search: "memes", "genz", "tiktok", "daily memes"
3. Filter by: Channels
4. Look for: 10k+ subscribers

**Method 2: Telegram Directory Sites**
- tlgrm.eu/channels
- telegramchannels.me
- combot.org/telegram/top/channels

**Method 3: Follow the Network**
1. Join one popular channel
2. Check their "similar channels" links
3. Follow recommendation chains

### Target Channel Types

**Ideal:**
- Meme channels (Gen Z focused)
- TikTok compilation channels
- Daily video channels
- Trend/viral content channels

**Channel Indicators:**
- Posts 3-10 times per day
- High engagement (views, shares)
- Video-focused
- Gen Z language/memes
- Active comment section

### Engagement Strategy

**Option 1: Sponsored Posts**

**Find admin contact:**
- Usually in channel description
- "For ads: @username"

**Message template:**
```
hi! interested in sponsored post for your channel

I have an app that might resonate with your audience - aura tracking/leaderboards

would you be interested in a post? what are your rates?

can provide video or custom content

lmk! 🔥
```

**Typical rates:**
- 10k subs: $20-50 per post
- 50k subs: $50-100 per post
- 100k+ subs: $100-300 per post

**Option 2: Create Official Channel**

1. Create: @AuraApp (or similar)
2. Post updates, leaderboards, highlights
3. Cross-promote in messages
4. Link from app
5. Use for announcements

**Content to post:**

## WhatsApp Groups - How to Leverage

### Finding Groups

**Challenge:** WhatsApp groups are mostly private

**Strategies:**

**1. Start with Friends**
- Share in your friend groups
- Ask them to share in their groups
- Organic friend-to-friend spread

**2. School/University Groups**
- If you have access to class groups
- Campus-wide groups
- Club/activity groups

**3. Ask Users**
- Early users will be in groups
- Encourage them to share
- Provide shareable content

### WhatsApp Strategy

**Status Feature (Key!):**

1. Users post app moments to Status
2. Their contacts see it
3. Contacts ask about it / download
4. Ripple effect

**Optimize for Status:**
- Create shareable wins
- "I just ranked #427!" → Status worthy
- Battle wins → Status worthy
- Challenge wins → Status worthy

**Make it Status-Friendly:**
- Auto-generate shareable graphics
- "Share to Status" button in app
- Pre-formatted with app branding
- One-tap share

### Content That Gets Forwarded

**In WhatsApp Groups:**
- Funny aura moments
- Impressive rankings
- Battle results (if dramatic)
- Challenges (FOMO)

**Make it Forwardable:**
- Under 30 seconds
- No sound required
- Clear visual message
- Share button prominent

## Red Flags to Watch For

### Getting Banned/Blocked

**Signs:**
- Comments getting deleted
- DMs not going through
- Posts removed by mods
- Account shadowbanned

**If this happens:**
- You're being too promotional
- Pull back on mentions
- Focus on genuine participation
- Build trust first

### Low Engagement

**Signs:**
- No responses to outreach
- Comments ignored
- No downloads from efforts

**If this happens:**
- Content not resonating
- Timing might be off
- Wrong communities
- Reassess messaging

### Wrong Audience

**Signs:**
- Users don't understand aura culture
- Confusion about the concept
- Wrong age demographic

**If this happens:**
- You're in wrong communities
- Find younger/meme-focused spaces
- TikTok first, others second
