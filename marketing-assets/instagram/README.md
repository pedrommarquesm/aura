## Customization Guide

All graphics are templates. Here's how to customize them:

### Update Text
- Use Figma, Canva, or Photoshop
- Keep the same fonts (bold sans-serif)
- Maintain color scheme (dark bg, white text, fire red/orange accents)

### Add Real Data
Replace placeholder content with:
- **Leaderboard:** Real usernames and aura counts from app
- **Battles:** Real battle results with actual percentages
- **Challenges:** Real challenge names and winners
- **Stats:** Real metrics from your analytics

### User Content
- Screenshot user posts for battle graphics
- Use real usernames (with permission or anonymized)
- Show actual aura numbers from the app

## Brand Consistency

### Colors
- Background: #1a1a1a (dark charcoal) or pure black
- Text: #ffffff (white)
- Accents: #ff4500 (fire red/orange) or #ffd700 (gold for winners)
- Stats: #4a9eff (ice blue)

### Typography
- Bold, heavy sans-serif
- High contrast
- Large numbers for aura/ranks
- ALL CAPS for emphasis

### Tone
- Competitive but not toxic
- Confident but not arrogant  
- Casual but not sloppy
- Direct but not aggressive

### Don't
- Use corporate stock photos
- Use generic gradients
- Use pastel colors
- Use cursive/script fonts
- Use emojis excessively (1-2 per caption max)

## Performance Tracking

### Track for Each Post
- Reach
- Engagement rate
- Saves (high intent metric)
- Shares
- Profile visits
- Link clicks

### Winning Content
If a post performs 2x above average:
- Create similar content
- Boost with paid ads
- Replicate the format

### Underperforming Content
If a post performs below 50% of average:
- Try different posting time
- Adjust caption
- Don't repeat that format

## A/B Testing Ideas

Test these variations:

**Captions:**
- Short (1-2 lines) vs Long (5-10 lines)
- Question CTA vs Direct CTA
- Emoji placement (beginning vs end)

**Graphics:**
- Light text on dark bg vs Dark text on light bg
- Minimal design vs More visual elements
- Data-heavy (leaderboards) vs Emotion-heavy (testimonials)

**Timing:**
- Morning (8-10am) vs Evening (6-9pm)
- Weekday vs Weekend

## Legal & Compliance

### User Content
- Always get permission before featuring user posts
- Tag users when featuring their content
- Respect privacy - blur faces if needed

### Disclosures
- Mark sponsored posts with #ad or #sponsored
- Comply with FTC guidelines for influencer content
- Be transparent about partnerships

### Copyright
- Use only licensed music in Reels
- Don't use copyrighted images without permission
- Create original content when possible

## Crisis Response

### If Negative Comments
- Respond within 2 hours
- Stay calm and professional
- Use response templates from `docs/launch-content.md`
- Move to DMs if needed

### If Technical Issues
- Post transparently on Stories
- Give timeline for fix
- Offer compensation if appropriate
- Update when resolved

### If Inappropriate Content Tagged
- Hide or remove immediately
- Report to Instagram if needed
- Review moderation settings
- Address in Stories if viral
