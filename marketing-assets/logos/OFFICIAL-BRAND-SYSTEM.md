## Usage Guidelines

### DO:
✅ Use app icon for mobile contexts
✅ Use simple favicon for web favicons
✅ Use horizontal logo for web headers
✅ Export at proper sizes for each platform
✅ Maintain black background in all uses
✅ Keep aspect ratio locked (never stretch)
✅ Allow the detail to shine (don't add effects)

### DON'T:
❌ Use app icon as favicon (too detailed for 16px)
❌ Use favicon as app icon (lacks the arrow)
❌ Stretch or distort any version
❌ Add drop shadows or effects
❌ Use on busy backgrounds
❌ Make smaller than minimum sizes
❌ Change colors
❌ Add borders or frames

## Technical Specifications

### App Icon (FINAL)
- **Format:** PNG with transparency
- **Color space:** RGB
- **Resolution:** 72 DPI minimum, 300 DPI for print
- **File size:** ~1.1MB (high quality)
- **Dimensions:** 1024×1024px square

### Favicon (Simple)
- **Format:** PNG, ICO
- **Color space:** RGB
- **Resolution:** 72 DPI
- **File size:** ~1.4MB source (will be much smaller at 32px/16px)
- **Dimensions:** 512×512px source, export to 32px and 16px

- **Format:** PNG with transparency
- **Color space:** RGB
- **Resolution:** 72 DPI, 300 DPI for print
